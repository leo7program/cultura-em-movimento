Cultura em Movimento

Site institucional da Cultura em Movimento, iniciativa de educação intercultural que aproxima jovens da diversidade cultural por meio de oficinas e experiências práticas. O site apresenta quem somos, missão e visão, setores (História, Música e Gastronomia), valores e canais de contato (WhatsApp, e-mail e Instagram).

Feito com HTML, CSS e JavaScript puros, em um único arquivo (index.html), e publicado com GitHub Pages.

Projeto desenvolvido com vibe coding, usando IA para gerar e ajustar o código a partir de descrições em linguagem natural.
